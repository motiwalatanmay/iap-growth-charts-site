# IAP Growth Charts — camp screening tool

Public, compiled build of Dr. Tanmay's IAP 2015 height-for-age and BMI-for-age
plotting tool for Swasthya Saathi camp screening (ages 5y0m–18y0m).

This repository holds the **compiled bundle only** (static HTML/CSS/JS). It is
served to the camp team via GitHub Pages. The source code is kept in a separate
private repository.

- Clinical basis: IAP 2015 growth reference tables (height-for-age, BMI-for-age).
- Live URL: see the repository's GitHub Pages link (Settings → Pages).
- Not a medical device. For screening use by trained camp staff only.
