# WHO & IAP Growth Charts — camp screening tool

Public, compiled build of Dr. Tanmay's growth-charts tool for Swasthya Saathi
camp screening. It opens on an age picker and covers two references:

- **WHO Child Growth Standards (2006)** — birth to before the fifth birthday.
- **IAP 2015** height-for-age and BMI-for-age — 5y0m to 18y0m.

This repository holds the **compiled bundle only** (static HTML/CSS/JS). It is
served to the camp team via GitHub Pages. The source code is kept in a separate
private repository.

- Live URL: see the repository's GitHub Pages link (Settings → Pages).
- No child details are saved.
- Not a medical device. For screening use by trained camp staff only.
